## Runtime manifest

- **Location:** `storage/app/private/runtime-manifest.json`
- **Coexists with:** `storage/app/private/release.json` (not replaced)
- **Generated by:** `php artisan central-wallet:write-runtime-manifest`
- **Overlay helper:** `tools/commands/central-wallet-runtime-manifest.sh overlay <prompt-id> <source-commit> <rollback-ref>`

Overlay deployments may intentionally differ from `release.json.build`. Drift verifier reports this as **WARN**, not FAIL.

## Drift detection

```bash
php artisan central-wallet:verify-deployment-drift
php artisan central-wallet:verify-deployment-drift --json
```

Provider checks include:

- contract files present
- contract version match
- required routes registered (`wallet-visibility`, etc.)
- runtime manifest contract version
- runtime file SHA-256 hashes
